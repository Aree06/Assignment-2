Overview:
This project is a portfolio website created using HTML, CSS, Bootstrap, Javascript, and EJS templates. It includes an about me section, projects page, and contact me information. The site uses multiple pages and is easy to navigate.

Pages & Features:
Home page
    - This page is a welcoming landing page that introduces the users to my site 
About me page
    - This page contains introducion and some fun facts about me
    - Includes a "Watch Video" button that allows users to view an introduction video
Video page
    - This page is linked from the About Me page and is dedicated to playing the personal introduction video 
Projects page
    - This page showcases a few projects along woth breif descriptions using Bootsrap Carousels
Contact me page
    - This page is a for for users to reach out to me 
    - This form collecs the users first name, last name, email, and comments
    - Includes a client-side form vaildation with Bootstrap validation script

Layout Components:

Footer
